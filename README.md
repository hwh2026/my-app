# 历史通关棋 · 中国历史大通关

一款面向小学中高年级的**中国历史闯关答题小游戏**，忠实还原《历史通关棋》桌游玩法，支持**单人 vs 电脑**和**4 人跨地域联机**。

## ✨ 功能一览

- 🗺️ **62 格历史时间轴棋盘**：从元谋人（170万年前）一路走到中华人民共和国成立（1949），每格带历史事件+年代
- 🎲 **掷骰子前进**：刚好到终点才算赢，多余点数往回走
- ❓ **301 道选择题**：覆盖上下五千年，4 选 1，自动判分，每题带"知识小贴士"解析
- 🎯 **跟随朝代抽题**：走到唐朝区就考唐朝题，题不足时全库随机
- 🕳️ **8 个副本小关卡**：连答 3 题，全对通关大奖，错 1 题退出
- 🎴 **16 张技能卡**：偷卡、换位、定身、再掷、护盾、锦囊妙计等（含原版 4 张）
- 🤖 **三档 AI 难度**：简单 40% / 普通 55% / 困难 70% 答对率
- 🌐 **4 人联机**：房间号加入、全员抢答（服务器时间判先后）、实时同步、断线自动重连
- 🔊 **合成音效**：骰子/答对/答错/胜利，无需任何音频文件，一键静音
- 📱 **手机+电脑自适应**，卡通中国风界面

## 🚀 部署步骤（共 3 步）

### 第 1 步：初始化 Supabase 数据库（联机必需）

1. 打开 [supabase.com](https://supabase.com)，用邮箱登录
2. 进入你的项目 → 左侧菜单 **SQL Editor** → **New query**
3. 把 `supabase-setup.sql` 的**全部内容**粘贴进去，点 **Run**（会创建 `rooms` 和 `buzzes` 两张表）

> 数据库连接信息（URL 和 key）已写入 `multiplayer.js` 顶部，无需修改。

### 第 2 步：本地试玩（可选）

```bash
# 在项目目录下启动本地服务器
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

单人模式可离线玩；联机模式需要完成第 1 步。

### 第 3 步：部署到 Vercel（免费）

1. 把整个项目文件夹上传到 GitHub 仓库
2. 打开 [vercel.com](https://vercel.com)，用 GitHub 登录
3. **Add New Project** → 选择该仓库 → 直接 **Deploy**（无需任何配置，是纯静态站）
4. 部署完成后得到一个网址，4 个人各自打开即可联机

## 🎮 玩法速览

1. 2-4 人轮流掷骰子，按点数前进
2. 踩中 **答题格**：抽题抢答（联机）/ 自己答（单人），答对得能量卡
3. 踩中 **技能卡**：随机获得技能效果
4. 踩中 **黄色副本格**：连答 3 题，全对有大奖
5. 踩中 **红色格**：后退惩罚（可用护盾抵消）
6. 到达终点者按名次奖励能量卡；凑够人数后游戏结束，**能量卡积分最高者获胜**

## 📌 说明与后续可优化

- **联机是回合制**，用轮询同步（约 1.4 秒刷新），抢答用数据库原子插入保证"先到先得"
- 房间号即"密码"，无需注册登录，适合家庭/同学使用
- 可优化项：技能卡指定目标改为手动选择、补答链更完善、增加音效开关持久化、题目按年级细分、加入背景音乐
